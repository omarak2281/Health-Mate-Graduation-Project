# Health Mate

Health Mate is a remote patient-monitoring system for chronic cardiovascular
conditions, built around a Flutter mobile app, a FastAPI backend, two custom
IoT devices, and two purpose-built AI models.

**Full documentation lives in [`Docs/`](Docs/README.md).** Start there —
it's a source-code-verified overview with links to architecture, database,
API, AI model, frontend, and IoT documentation, plus the full graduation
thesis document (`.md`, `.tex`, and `.docx`).
